## 🧑‍💻 About Me

I'm a Computer Science undergraduate at **Vellore Institute of Technology** focused on becoming a strong **Software Development Engineer**, with a particular interest in **Java backend engineering, distributed systems, and system design**.

I enjoy going beyond frameworks and understanding what happens underneath:

```text
Request
   ↓
Load Balancer
   ↓
Backend Service
   ↓
Cache / Database
   ↓
Message / External Service
   ↓
Response
```

My curiosity is around questions like:

* What happens when traffic suddenly increases?
* Where does latency actually come from?
* What happens when a database goes down?
* How should services communicate reliably?
* How do we design APIs that remain maintainable?
* How can systems fail gracefully instead of catastrophically?

I want to build software that is **correct, observable, scalable, secure, and maintainable**.
